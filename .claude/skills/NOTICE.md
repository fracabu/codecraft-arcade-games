# Provenienza delle skill

Le cartelle di questa directory vengono da
[gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)
e sono distribuite con la licenza Apache-2.0 (testo in `LICENSE`).

Sono state installate il 20/11/2026 con
`npx skills add gamedev-skills/awesome-gamedev-agent-skills -a claude-code --copy`.
Sono le 9 skill usate per costruire i giochi: router, phaser-core, phaser-arcade-physics, game-feel,
input-systems, performance-optimization, game-ui-ux, prototype-fast e puzzle. I file non sono stati modificati.
